Open-source licenses & source

PixelPort is an independent frontend. No Nintendo commercial game images, BIOS files, or copyrighted game artwork are included. The small original NES controller demo was written for PixelPort; its source is included in the PixelPort source archive.

JSNES

Uncompressed NES files use JSNES 2.1.0, a JavaScript CPU/PPU/APU emulator with Canvas 2D rendering. Apache-2.0 license · Source project. The compiled JSNES library is unmodified.

PeerJS

Online rooms use PeerJS 1.5.5 for signaling and WebRTC connections. MIT license · Source project.

Built-in mod patches

Original games are supplied by players. See patch authors, source locations and pinned hashes. Mod patches remain the work of their respective creators; the PixelPort frontend license does not relicense them.

ROM patching and ZIP export

Unmodified IPS/BPS parsers from Rom Patcher JS (MIT license); ZIP export uses fflate 0.8.2 (MIT license).

EmulatorJS

The browser downloads EmulatorJS 4.2.3 for older systems, and the official nightly Azahar core for 3DS, from the official EmulatorJS CDN. EmulatorJS is GPL-3.0 licensed; individual cores retain their respective licenses.

Dolphin browser port

The GameCube/Wii player uses dougchansan’s wasm-dolphin, a derivative of Dolphin licensed under GPL-2.0-or-later. PixelPort adds a local-file message bridge, embedded layout, and explicit failure handling. GameCube retains the original core. The separate experimental Wii core adds one emulated sideways Wii Remote, button-driven shake and stick-driven tilt.
